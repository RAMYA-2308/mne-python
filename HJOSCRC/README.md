# H-JOSCRC reproducibility materials

This directory is reserved for the H-JOSCRC study materials. The repository currently hosts an unrelated MNE-Python project, so H-JOSCRC files must not be published here. A dedicated public repository should be created after the authors approve the release of the curated cohort, source code, model artifacts, and analysis outputs.

Until that repository is available, this README intentionally does not claim that the H-JOSCRC code or curated dataset is publicly available.
